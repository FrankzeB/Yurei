# Yūrei (幽霊)

Mi primer "juego" en Unity, basado en C# y de terror. La fecha puede parecer reciente, pero lo desarrolle y lo abandonae el 8 de marzo del 2023. Una écpoca bastante experimental de mi que me gustaria guardar.

## Descarga

[Releases](https://github.com/FrankzeB/Yurei/releases)

## Requisitos

- Windows 64 bits

## Cómo abrirlo

1. Extraé el .zip completo.
2. Abrí `Yūrei (幽霊)_beta 0.1.exe` sin sacarlo de su carpeta.

## Aviso

Windows SmartScreen o tu antivirus pueden marcar el .exe porque no está firmado.
